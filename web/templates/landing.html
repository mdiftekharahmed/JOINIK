The Problem

Reactive Systems Fail at the Critical Moment

Traditional retail security only responds after an intrusion has occurred — by which point damage and loss are already inevitable.

CCTV Records, Does Not Prevent

Cameras document what happens after entry. They do not prevent the break-in and are frequently disabled by cutting power before entry.

PIR Sensors Trigger After Entry

Passive infrared motion sensors only detect presence inside the premises. By the time they fire, physical breach has already succeeded.

Single Point of Failure

Cutting the power line disables conventional alarm systems entirely, removing all protection at precisely the moment an attack begins.

Enterprise Solutions Are Unaffordable

Professional pre-breach detection systems are cost-prohibitive for small and medium retail operators who need them most.

The JOINIK Approach

JOINIK reverses the detection paradigm. By analyzing vibration frequency signatures, power status, and interior motion simultaneously, the system identifies an attack while it is still in progress — before the shutter is breached.

Detects drilling, cutting, and hammering via vibration signature analysis
Treats a grid power cut as a direct threat indicator
Mesh topology ensures no single node failure disrupts the network
Battery backup maintains operation when mains power is cut
Edge-level filtering eliminates false alarms from wind, animals, and traffic
Platform Features

Engineered for Precision Detection

Every component of JOINIK is designed around a single objective — detecting a threat while an attacker can still be stopped.

Pre-Breach Detection

Identifies an attack while it is still in progress. Shutter cutting, drilling, and hammering are classified using multi-sensor vibration analysis before physical entry succeeds.

Multi-Sensor Fusion

Combines vibration, accelerometer, gyroscope, power monitoring, and interior PIR data to produce a single, reliable threat confidence score per 10-second window.

Resilient Mesh Network

Distributed ESP-MESH/ESP-NOW topology means no single node failure can disable the system. The network re-routes around any destroyed or offline node automatically.

Power Sabotage Detection

A mains power cut is treated as a direct security event. Each node includes battery backup, maintaining full sensor operation when the grid is deliberately disabled.

Edge AI Signal Processing

Threat confidence scoring runs at the gateway edge, not in the cloud. Real-time classification filters wind, traffic, and animal vibrations to eliminate false alarms.

Cloud Dashboard and Analytics

Full telemetry logging, historical session analysis, risk timeline visualization, alarm management, and CSV export for compliance and incident reporting.

Detection Pipeline

From Sensor to Alert in Seconds

01

Continuous Sensor Sampling

ESP32 nodes sample vibration intensity, 3-axis accelerometer, gyroscope, power status, and CCTV line continuity at high frequency and transmit via the mesh network.

02

10-Second Tumbling Window Analysis

The edge gateway aggregates incoming telemetry into 10-second non-overlapping windows. Statistical features are extracted: persistence ratio, accel magnitude, gyro magnitude, and motion ratio.

03

Rule-Based Multi-Sensor Classification

Seven defined threat scenarios from isolated vibration to coordinated multi-sensor events are evaluated against each window. A risk score from 0 to 100 and risk level are assigned.

04

Immediate Alert Dispatch

When a Medium, High, or Critical risk is detected, alarms are raised, WebSocket push notifications are sent to the dashboard, and SMS and call alerts are dispatched to the owner and emergency contacts.

05

Persistent Analysis Storage

Every analysis window is stored in a dedicated PostgreSQL database, enabling full audit trail, historical session replay, and compliance reporting.

System Architecture

Four-Layer Security Stack

A layered architecture from hardware to cloud, with no single point of failure at any layer.

Sensor Layer

ESP32 nodes with vibration sensor, 3-axis IMU, power monitor, and CCTV line sensor. Battery-backed. Tamper-detected.

Mesh Network

ESP-MESH / ESP-NOW resilient topology. Self-healing. Operates independently of internet connectivity.

Edge Gateway

ThingsBoard IoT platform. Local signal fusion and AI classification. 10-second tumbling window analysis engine.

Cloud Dashboard

Django and PostgreSQL with WebSocket real-time dashboard. Alarm management, analytics, and mobile alert dispatch.
